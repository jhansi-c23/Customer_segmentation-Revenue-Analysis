Project Overview

This project focuses on analyzing customer purchasing behavior and revenue performance using SQL. The objective is to identify valuable customer segments, understand sales trends, and generate business insights that can support data-driven decision-making.

Objectives
Analyze customer purchase history and spending patterns.
Segment customers based on purchasing behavior.
Track revenue trends and sales performance.
Identify inactive customers and high-value customers.
Generate actionable business insights through SQL queries.
